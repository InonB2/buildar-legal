# buildar-legal

Two static pages for BuildAR Pro's Play Store listing: privacy policy and account deletion.

**This repository's source is private by design.** GitHub Pages serves the rendered
HTML publicly regardless of repo visibility — that's the point: the source stays
private, but the pages below are publicly viewable with no login wall, satisfying
Google Play's requirement for a publicly accessible privacy policy and
account-deletion URL.
